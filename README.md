# Artist_pad
AI油画创作系统插件优化交互方案

交互原则

- **以图片为操作对象**：能力调用明确绑定当前图片，避免用户在独立表单中重复描述上下文。
- **能力持续随图**：Skill 是可重复使用的专业能力，不是一次性菜单命令；挂载状态和调整设置随图片保留。
- **先可视探索，再精细控制**：优先通过画布示意、拖拽和方向卡片表达意图，详细参数作为进一步调整入口。
- **候选由用户决定**：生成结果先进入比较阶段，采用后才放入画布；原图始终保留，支持回退与继续探索。
- **项目资产提供上下文**：项目记忆、参考图和已挂载能力共同参与创作，形成可复用的项目工作方式。

1.从画布图片进入能力调用

选中画布中的图片后，图片旁出现轻量操作卡片。用户可以直接调用能力或进行局部修改；打开“能力与项目资产”后，可浏览构图探索、光色推演、材质发展等能力，并将需要的能力附加到当前图片

2.能力工作台

工作台明确显示操作源图，提供能力类别切换和可视化调整区。以“构图探索”为例，用户可以在画面示意区拖动人物、调整视觉重心，并选择关系聚焦、空间舒展、环形叙事等构图方向。
用户可以保留人物身份、人物数量、创作主题等约束，再展开详细参数进行精调；也可以添加参考图，通过文字或语音补充本轮意图。已锁定的约束在后续候选探索中继续保留。

点击生成后，工作台展示候选方向。用户可以切换候选、比较方案，并按住查看原图，再决定是否采用。候选比较阶段不会自动替换画布原图。
